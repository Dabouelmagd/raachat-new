# اختبارات واجهة رع شات

اختبارات Playwright بتشتغل على **نسخة الملف الواحد** (`dist-single/index.html`) في وضع
الديمو — يعني بدون سيرفر ولا داتابيز، فسريعة وبتشتغل في أي مكان.

**مساحة منفصلة بتبعياتها:** `test/package.json` مش مربوط بجذر المشروع، و`Dockerfile.web`
بيقرا من الجذر بس (`package*.json` و`index.html` و`src` و`public`) — فتبعيات الاختبارات
**عمرها ما تدخل في صورة الإنتاج** ولا تبطّل البناء.

## التشغيل

```bash
# ١) من جذر المشروع: ابني نسخة المعاينة
npx tsc -b && npx vite build -c vite.single.config.ts

# ٢) من هنا
cd test && npm ci && npx playwright install chromium && npm test
```

لو عايزة تشوفي المتصفح وهو شغال: `npm run test:headed`.

## إيه اللي مغطّى

| الملف | بيحمي إيه |
|---|---|
| `ui/age.spec.ts` | سن الخدمات: البالغ يشوف المحفظة، القاصر يشوف قفل بيشرح إن باقي التطبيق مفتوح، الفئة ١٨–٢١ تشوف بطاقة السقوف، و٢١+ بلا سقوف، وحقل تاريخ الميلاد يرفض التواريخ الغلط |
| `ui/legal.spec.ts` | نصوص الخصوصية والشروط تطابق سلوك التطبيق فعلًا (لكل الأعمار · حدود لحد ٢١ · تنبيه المسوّدة · حفظ أحداث إعلانات الأطفال)، والنسختين عربي/إنجليزي، ومفيش تمدد أفقي على الموبايل |
| `ui/shell.spec.ts` | سهم الرجوع · زر الوضع الليلي · زر البحث · كل التابات تفتح من غير أخطاء JS |

## قواعد كتابة اختبار جديد هنا

- **الديمو بيحفظ الملف الشخصي في الذاكرة**، فالاختبارات بتشتغل واحد ورا التاني
  (`workers: 1`) — متعمليش توازي.
- النوافذ المنبثقة (دفتر الأسماء / الإعلان) بتحجب الكليك: استخدمي `clearOverlays`
  أو `tab()` من `helpers.ts` اللي بتعملها لوحدها.
- الوصول للملف الشخصي من زرار اسم الحساب (`openProfile`) — التطبيق على `MemoryRouter`
  فمفيش روابط مباشرة بالعنوان.
- `expectNoPageErrors(page)` في آخر أي اختبار تنقل، عشان نكشف أخطاء JS الصامتة.
