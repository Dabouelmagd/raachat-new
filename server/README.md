# رع شات — الـ API (Node + Express + Prisma + PostgreSQL)

الواجهة (`../src`) لسه شغّالة ببيانات وهمية؛ ده الباك إند اللي هتتوصّل بيه. العقد الكامل في `../openapi.yaml`.

## تشغيل محلي
```bash
cd server
cp .env.example .env                 # عدّلي JWT_SECRET
docker compose up db -d              # PostgreSQL فقط
npm install                          # بيعمل prisma generate تلقائيًا
npx prisma migrate deploy            # أو: npx prisma migrate dev
npm run db:seed                      # بيانات تجريبية (اختياري)
npm run dev                          # http://localhost:4000
npm test                             # اختبارات على PostgreSQL حقيقي (embedded)
```
تشغيل كامل بـ Docker: `JWT_SECRET=… docker compose up --build`.

> **مهم عن الهجرة الأولى:** `prisma/migrations/…_init/migration.sql` اتولّدت بسكربت مني لأن بيئة التطوير اللي اتبنى فيها
> ما كانتش تقدر تنزّل محرك Prisma. اتجرّبت على PostgreSQL 16 والاختبارات بتعدّي، لكن لو `prisma migrate dev`
> اشتكى من اختلاف: احذفي مجلد `prisma/migrations` وشغّلي `npx prisma migrate dev --name init` (المخطط `schema.prisma` هو المرجع).

## اللي شغّال
| المجال | المسارات |
|---|---|
| الدخول | OTP بالتليفون/الإيميل (5 دقائق، 5 محاولات، 5 طلبات/ساعة) → access (15 د) + refresh (30 يوم، بيتدوّر) · `/sessions` لإنهاء الجلسات |
| الملف الشخصي | `GET/PATCH /me` · `GET /users?q=` |
| المحادثات | dm بلا تكرار · جروبات **بلا حد أقصى للأعضاء** مع لون/أيقونة/صورة · جروبات عامة وانضمام · إضافة أعضاء · تعديل الشكل |
| الرسائل | إرسال/رد/تعديل/حذف/تفاعلات/ترقيم بالصفحات/مقروءة · مرفقات ورسائل صوتية · `POST /uploads` |
| لحظي (Socket.IO) | `message:new/updated/deleted` · `thread:new/updated` · `typing` (التوكن في `auth.token`) |
| القصص والمكالمات | `/stories` (24 ساعة، بصورة) · `/calls` سجل المكالمات |
| الترجمة | `POST /translate` (Google Cloud Translation عند ضبط `GOOGLE_TRANSLATE_KEY`، وإلا 501) |

المخطط (`prisma/schema.prisma`) جاهز كمان للمحفظة والفواتير والعروض والغرف الصوتية والإعلانات، لكن مساراتها لسه ما اتبنتش.

## قبل الإنتاج
- **OTP:** في production `consoleSender` بيتبدّل بـ `providerSender` (Twilio للـ SMS، Resend للإيميل). كود الإرسال ما اتجرّبش على الشبكة الحقيقية — جرّبيه بمفاتيحك. `OTP_DEV_CODE` ممنوع في production.
- **الملفات:** `/uploads` على قرص السيرفر. للإنتاج بدّليها بـ S3/R2/Supabase Storage (نفس شكل الرد).
- **المكالمات الفعلية:** السيرفر بيسجّل السجل بس. الصوت/الفيديو الحقيقي محتاج WebRTC (LiveKit/Jitsi) وتوقيع (signaling).
- **الترجمة الفورية في المكالمات:** محتاجة STT ثم `/translate` ثم TTS كبث لحظي.
- **البحث بالذكاء الاصطناعي** (`/search/ai`) والمحفظة والغرف: الخطوة الجاية.

## المحفظة والدفع (`routes/wallet.ts`)

`GET /wallet` · `GET /wallet/offers` · `PUT /wallet/pin` · `POST /wallet/quote` · `POST /wallet/pay` · `POST /wallet/topup`

- الرصيد بيتخصم ذريًا (`UPDATE … WHERE balance >= total`) فمفيش سباق بين طلبين، والدفع idempotent بمفتاح `idempotencyKey`.
- الـ PIN بيتخزّن scrypt+salt، و5 محاولات غلط تقفل المحفظة 15 دقيقة. الخصم بيتحسب على السيرفر.
- **غير مكتمل:** `POST /wallet/topup` في production بيرجّع 501 لحد ما توصّلي بوابة دفع (Paymob/Fawry…)؛ وقيمة الفاتورة جاية من العميل لأن مفيش تكامل مع جهة الفاتورة (Fawry/aggregator) لسه. الإيصال يفضل «تجريبي» لحد ده.

## الغرف الصوتية والإعلانات والبحث

- **الغرف** (`routes/rooms.ts`): `GET/POST /rooms` · `POST /rooms/:id/join|leave` · `PUT /rooms/:id/mute` · `DELETE /rooms/:id`. الحضور لحظي (`room:changed` عبر Socket.IO) وبيتشال المستخدم تلقائيًا لما آخر اتصال له يقفل. الهوية المؤقتة بيحددها **السيرفر** ومش بيتبعت الاسم ولا الـ userId الحقيقي لأي مشارك تاني. **ده الحضور والتحكم بس — الصوت نفسه (WebRTC) لسه مش مبني.** «منع لقطة الشاشة» ما ينفعش يتضمن من السيرفر.
- **الإعلانات** (`routes/ads.ts`): السيرفر بيسجّل الأحداث (ظهور/ضغط/إغلاق) وبيوحّد مواعيد اليوم بين أجهزة المستخدم. الكتالوج نفسه لسه في الواجهة (مفيش خادم إعلانات/لوحة معلنين).
- **البحث** (`routes/search.ts`): بحث نصي بتوحيد عربي (تشكيل/همزات/ى/ة) على رسائل المستخدم والأشخاص والجروبات. **مفيش embeddings ولا نموذج لغوي**؛ «الإجابة المُركّبة» في البحث العميق لسه محلية في الواجهة.
- ملاحظة: قاعدة البيانات لازم تكون بترميز UTF8 (Postgres في Docker كده افتراضيًا).

## مكالمات الصوت/الفيديو والصوت في الغرف (WebRTC)

- **السيرفر = signaling فقط** (`src/rtc.ts`): `call:invite|answer|signal|end` للمكالمات 1:1، و`rtc:join|signal|leave` لصوت الغرف (mesh حتى ٨ أشخاص). الوسائط بتمشي P2P أو عبر TURN ومش بتعدّي على السيرفر. السيرفر بيكتب سجل المكالمات للطرفين (بما فيها الفايتة/المرفوضة).
- `GET /rtc/config` بيرجّع STUN + TURN بكلمة سر مؤقتة (HMAC). **من غير TURN المكالمات بتفشل خلف شبكات مقفولة** (شبكات شغل/بعض الموبايل). شغّلي `docker compose --profile turn up` وضبطي `TURN_URLS` و`TURN_SECRET`.
- **قيود معروفة:** الحالة في ذاكرة instance واحد (للتوسع: Redis adapter + حالة المكالمات في Redis)؛ مفيش إشعارات push للمكالمات الواردة (المتلقي لازم يكون فاتح التطبيق، وإلا الرد «أوفلاين»)؛ مكالمات جماعية بالفيديو وSFU (LiveKit) غير مبنية؛ الترجمة الفورية داخل المكالمة محتاجة STT/TTS (لسه).
- متجرّب فعليًا: مكالمة فيديو وصوت الغرفة بين متصفحين (Chromium بكاميرا/مايك افتراضيين) — الوسائط اتبادلت فعلًا. **ما اتجرّبش** على موبايلات حقيقية أو عبر TURN.

## إشعارات Push
- ولّدي مفاتيح VAPID مرة واحدة: `npm run vapid` وحطي `VAPID_PUBLIC` و`VAPID_PRIVATE` (و`VAPID_SUBJECT`) في البيئة. **المفتاح الخاص سري** — لو اتغيّر كل الاشتراكات القديمة بتموت.
- `GET /push/key` (المفتاح العام) · `POST /push/subscribe` · `POST /push/unsubscribe`.
- الرسالة: إشعار للأعضاء **الأوفلاين بس** (مفيش socket متصل). المكالمة: لو المتلقي أوفلاين وعنده اشتراك، المكالمة بترن (٤٥ث) ويوصله إشعار؛ لما يفتح التطبيق الواجهة بتسأل `call:pending`. لو المتصل قفل قبل الرد بيتبدّل إشعار الرنين بـ«مكالمة فائتة».
- بدون اشتراكات: سلوك المكالمة القديم (`offline`).
- iPhone: الإشعارات بتشتغل بس لو التطبيق مضاف للشاشة الرئيسية (PWA) وiOS 16.4+.
- نص الإشعار عربي من السيرفر (مش مترجم حسب لغة المستخدم).

## لوحة الإدارة: الفريق والصلاحيات (RBAC)
- **المالك:** أي رقم/إيميل في `OWNER_CONTACTS` أول ما يدخل بالكود بيتحوّل لمالك (كل الصلاحيات، مينفعش يتعدّل أو يتوقف). مفيش seed ولا أمر يدوي.
- **الأدوار الجاهزة:** مدير، إداري، محاسب، مشرف محتوى، دعم فني. بتتنشئ أول تشغيل، والمالك يعدّل صلاحياتها من اللوحة (التعديل بيفضل، مبيترجعش للافتراضي). تقدري تنشئي أدوار جديدة.
- **الصلاحيات الفعلية لكل عضو** = صلاحيات دوره + الإضافية (`grant`) − المسحوبة (`revoke`). الكتالوج في `src/lib/permissions.ts`، وأي صلاحية جديدة تتضاف هناك بس.
- **أمان:** مفيش حد يدّي صلاحية مش عنده (ماعدا المالك)؛ مفيش حد يعدّل صلاحياته بنفسه؛ العضو المعطّل بيتقفل عليه فورًا؛ إيقاف مستخدم بيلغي جلساته ويقفل الـ socket؛ كل إجراء في `AuditLog`.
- **Endpoints** (كلها `/admin/*` ومحتاجة توكن + صلاحية): `me` · `roles` · `staff` · `audit` · `users` (+`/status`) · `finance/tx` · `finance/summary` · `finance/tx/:id/refund` · `offers`.
- الاسترداد ذري: لو اتنين ضغطوا مع بعض واحد بس ينجح، والرصيد بيترجّع مرة واحدة (اللي اتخصم فعلًا).
- ⚠️ إيقاف/حظر المستخدم بيمنع الدخول والـ API؛ مفيش تجميد منفصل للمحفظة.

## خريطة الإعلانات (Ads inventory)
- **المواضع** `AdPlacement`: مقاس (px) + سعة (عدد معلنين في اليوم) + سعر اليوم. بتتزرع أول مرة (modal / banner / services / story) والمالك يعدّلها من الداشبورد.
- **الحملة** `AdCampaign` بتحجز مواضع `AdBooking` من تاريخ لتاريخ (YYYY-MM-DD بتوقيت القاهرة). السعر = مجموع أسعار المواضع × عدد الأيام (بيتثبّت وقت الحجز).
- الحالات: `pending` (حجز مؤقت بيحجز مكان) → `approved` → `paused`، أو `rejected` / `cancelled` (بتحرر المكان). «شغّالة/قادمة/انتهت» بتتحسب من التواريخ.
- الحجز بيتأكد من السعة يوم بيوم وبيتجاهل المواضع المقفولة `AdBlock` أو المتوقفة؛ وبيتنفّذ تحت `pg_advisory_xact_lock` فمفيش حجزين متزامنين على آخر مكان.
- الـ endpoints تحت `/admin/ads/*` (`ads.view` للقراءة، `ads.manage` للتغيير، وكلها في سجل المراجعة): `placements`، `inventory?from&days`، `quote`، `campaigns` (GET/POST/PATCH + `/:id/approve|reject|pause|resume|cancel`)، `blocks`.
- للتطبيق: `GET /ads/catalog` بيرجّع الحملات المعتمدة الشغّالة النهارده مع مواضعها. النافذة والبانرات وشاشة «الإعلانات» بتقرا منه في وضع الباك إند (والكتالوج المحلي في التجربة).
- الإحصائيات: `POST /ads/events` (مع `placement`) بيجمّع في `AdStat` يوميًا لكل حملة/موضع: ظهور فريد للمستخدم في اليوم + نقرات + إغلاقات. بتظهر في تبويب الحملات، والتفاصيل اليومية في `GET /admin/ads/campaigns/:id/stats`.

### أكواد الهدايا والأسعار
- **أكواد الهدية** `AdGift` (`RA-XXXX-XXXX`): مدة ١/٣/٦/١٢ شهر (٣٠/٩٠/١٨٠/٣٦٥ يوم)، اختياريًا مقيّدة بمواضع وبتاريخ صلاحية واسم عميل. بتتستخدم مرة واحدة وقت حجز الحملة (`giftCode`)، وبتخصم سعر المواضع المشمولة عن min(مدة الحملة، مدة الهدية)، والباقي بيتدفع. رفض الحملة (أو إلغاؤها قبل ما تبدأ) بيرجّع الكود. الـ endpoints: `GET/POST /admin/ads/gifts`، `DELETE /admin/ads/gifts/:id` (للغير مستخدم).
- **إعادة النشر**: زر في قائمة الحملات بيفتح نموذج حجز بنفس المحتوى والمواضع والمدة بتواريخ جديدة (بعد نهاية الحملة لو لسه شغالة، أو من النهارده) ويعيد فحص التوافر والسعر.
- **الأسعار الافتراضية** مبنية على متوسط CPM لميتا في مصر ≈ ٢٫٩$ ≈ ١٥٠ ج.م/ألف ظهور (سعر صرف ≈ ٥٢ ج.م): بانر الدردشات ١٥٠/يوم، بانر الخدمات ١٢٠، الستوري ٢٥٠، النافذة الكاملة ٤٠٠ (علاوة للمواضع كاملة الشاشة). **أرقام الظهور المتوقع (`dailyImpressions`) تقديرية** — عدّليها بالأرقام الفعلية والداشبورد بيحسب سعر الألف ظهور الفعلي ويقارنه بالسوق.
