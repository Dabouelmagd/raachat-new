الملف ده عن **نسخ المتجر**. الـAPK التجريبي ليه ملفه: `docs/mobile-apk.md`.

## ١) الفرق بين اللي عندنا واللي المتجر بياخده

| | التجربة على جهاز | جوجل بلاي | آبل |
|---|---|---|---|
| الملف | `raachat.apk` | `app-release.aab` | أرشيف من Xcode |
| التوقيع | مفتاح تصحيح | **مفتاح رفع** من Secrets | شهادة Apple Developer |
| مكان البناء | GitHub | GitHub | **ماك + Xcode** (مفيش بديل) |
| جاهز؟ | ✅ شغّال من ١٧ أكتوبر | ✅ الوظيفة جاهزة — ناقص المفتاح | ✅ المشروع جاهز — البناء عندك |

**ليه آبل لازم ماك:** `xcodebuild` و`pod` مابيشتغلوش غير على macOS، ومفيش منهم
حاجة في بيئة Claude ولا على سيرفر لينكس. فالأرشيف والرفع من جهازك، والريبو
بيدّيكي المشروع جاهزًا.

## ٢) 🔴 قبل أي بناء iOS: أصل التطبيق لازم يدخل `CORS_EXTRA`

أصل تطبيق Capacitor على iOS **`capacitor://localhost`** — مش `https://localhost`
زي أندرويد. و`iosScheme: "https"` **مابيشتغلش**: Capacitor بيرفضها في سكوت
ويرجع للافتراضي، لأن الشرط عنده إن الـWebView ما يكونش بيتعامل مع السكيمة أصلًا
(`WKWebView.handlesURLScheme("https")` بترجّع `true`) — مقروء من
`CAPInstanceDescriptor.swift` مش مستنتَج.

ومن غير الأصل ده في `CORS_ORIGIN`: التطبيق يفتح، يبان شغّالًا، و**مفيش ولا رسالة
بتتحمّل ومفيش ولا خطأ** في أي مكان — نفس عطل الـAPK في ١٨ أكتوبر بالظبط، لأن
نفس المفتاح بيحكم الطلبات (`app.ts`) **والسوكت** (`realtime.ts`).

على السيرفر، سطر واحد في `.env.production`:

```
CORS_EXTRA=,https://localhost,capacitor://localhost
```

ثلاث قواعد عليه:

1. **لازم يبدأ بفاصلة** — بيتلزق في آخر `CORS_ORIGIN` جوه compose.
2. **الأصول المحلية تفضل في الآخر** — `APP_URL` الفاضي بياخد أول أصل **غير
   محلّي**، ولو واحد منهم بقى الأول كل إيميل تحقق لكل المستخدمين رابطه يبقى
   `capacitor://localhost`. (و`firstPublicOrigin` بيعدّي الاتنين — متفحوص في
   `iosBuild.test.ts` على السلوك مش على النصّ.)
3. بعد التعديل **إعادة تشغيل الـapi**، والحكم `printenv` جوه الحاوية مش وجود
   السطر في الملف.

## ٣) جوجل بلاي — مفتاح الرفع

### المفتاح بيتولّد على جهازك، مش على السيرفر ومش هنا

عشان **ولا قيمة منه تعدّي في الشات ولا في لوج**. الخطوات كلها على الماك:

```bash
java -version
```

لو مفيش Java: `brew install --cask temurin` (أو Android Studio، جوّاه واحدة).

ولّدي كلمة سر في **مدير كلمات السر** الأول واحفظيها هناك باسم
«رع شات — مفتاح رفع أندرويد»، وبعدها:

```bash
cd ~/Desktop
keytool -genkeypair -v -keystore upload.jks -alias raachat-upload \
  -keyalg RSA -keysize 4096 -validity 10000
```

بيسأل على كلمة السر (الصقيها من مدير كلمات السر — مابتظهرش على الشاشة) وعلى
الاسم والجهة. استخدمي **نفس كلمة السر للمفتاح والمخزن** عشان ما تتلغبطيش.

### نقل المفتاح لـ GitHub Secrets — بلا ما يظهر على الشاشة

```bash
base64 -i upload.jks | pbcopy
```

ده بينسخه للحافظة **من غير ما يطبعه**. وبعدين على GitHub:
**Settings ← Secrets and variables ← Actions ← New repository secret**، والصقي.

الأربعة المطلوبة:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_B64` | اللي في الحافظة من الأمر فوق |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة السر من مدير كلمات السر |
| `ANDROID_KEY_ALIAS` | `raachat-upload` |
| `ANDROID_KEY_PASSWORD` | نفس كلمة السر |

**واحتفظي بـ`upload.jks` نفسه** في مدير كلمات السر كمرفق. ولو ضاع: مع **Play
App Signing** (المُفعَّل افتراضيًا للتطبيقات الجديدة) جوجل بتقدر تصفّر مفتاح
الرفع وتدّيكي غيره — فمفتاح الرفع مش نقطة فشل نهائية زي مفتاح التوقيع القديم.

### البناء

GitHub ← **Actions** ← «APK للموبايل» ← **Run workflow** ← فعّلي `aab`.

الناتج artifact اسمه **`raachat-aab`** فيه `app-release.aab`.

والوظيفة بتفحص بنفسها: الأسرار موجودة **قبل** ما تبني (سرّ ناقص مابيفشّلش
جريدل — بيطلّع حزمة **غير موقَّعة** وبلاي هي اللي ترفضها بعد الرفع)، وبعد
البناء بتتأكد إن الحزمة **موقَّعة فعلًا** (`jarsigner -verify`) وإن الواجهة
جوّاها.

### `versionCode`

بياخد رقم تشغيلة الوظيفة، فبيزيد لوحده. والرقم المستهلَك على بلاي **مابيرجعش
أبدًا**، فلو اتثبّت على ١ تاني رفعة بترفض.

## ٤) آبل — من الماك

على الماك، بعد `git pull`:

```bash
cd mobile && npm ci
```

```bash
cd .. && VITE_API_URL=https://api.raachateg.com VITE_SITE_URL=https://app.raachateg.com VITE_PUBLIC_SITE=https://raachateg.com npx vite build
```

```bash
cd mobile && npx cap sync ios
```

```bash
cd ios/App && pod install
```

```bash
cd ../.. && npm run open:ios
```

وبعدها في Xcode: **Signing & Capabilities** ← اختاري الـTeam بتاعتك (اسم الحزمة
`com.raachateg.app` متضبط أصلًا ومحمي باختبار) ← **Product > Archive** ←
**Distribute App**.

**اللي متضبط في الريبو:** اسم الحزمة · الاسم المعروض «رع شات» · أيقونة المتجر
١٠٢٤×١٠٢٤ بلا شفافية · وجُمل الأذونات الأربعة في `Info.plist` نفسه (ميكروفون ·
كاميرا · جهات اتصال · الصور). **وجملة إذن ناقصة بتوقّع التطبيق** (crash) مش
بترفض الإذن — فهي محميّة باختبار.

**حاجتان هتتسألي عليهما وأنا مش هقرّرهما عنك:**

1. **Export Compliance** — آبل بتسأل في كل رفعة هل التطبيق بيستخدم تشفيرًا غير
   مُعفى. إحنا على TLS وDTLS/SRTP القياسيين، وده المعتاد إنه مُعفى — إنما ده
   **إقرار تنظيمي** يتقال باسم الشركة، فجوابه قرارك (وينفع يتثبّت في
   `Info.plist` بعد ما تقرّري).
2. **تصنيف السن** — آبل بتعتبر الستوري والقنوات واكتشاف المجموعات «قدرة سوشيال
   ميديا»، وده بيفرض **١٣+** كحد أدنى عندها. والتفاصيل وباقي الإقرارات في
   `docs/legal/store-declarations.md`.

## ٥) ⚠️ اللي لسه بيمنع الرفع فعلًا (مش بناء)

النسختان بيتبنوا، إنما الرفع للمتجرين لسه عليه بنود **مش تقنية**:

- **الصفحات القانونية لسه عليها تنبيه مسوّدة** واسم مسؤول حماية البيانات (DPO)
  لسه خانة فاضية. ومذكرة المحامي النهائية (٥ نوفمبر ٢٠٢٦) حسمت **شكل** التعيين
  (قرار إداري داخلي موقَّع ومختوم بلا شهر عقاري، والمنشور = الاسم + الإيميل بس،
  والإخطار خلال ٣٠ يومًا)، و**رئيسة مجلس الإدارة ماينفعش تشغل المنصب**. والحالة:
  إجراءات ترخيص المسؤول جارية — فمفيش اسم لسه.
- ~~قناة التبليغ (NCMEC)~~ — **✅ اتقفل (٥ نوفمبر): المحامي قال إن القنوات المصرية
  المنشورة كافية، و«لا يُنصح بالتسجيل أو حتى مجرد نشر القناة» لـNCMEC** حاليًا،
  لأن التبليغ لجهة أمريكية = نقل بيانات خارج مصر بيتطلّب تصريحًا، ولأن نشر القناة
  وعد معلن بتبعات دولية. ولو اتعاد النظر، تُدرَج ضمن ملف تصريح النقل.
- **تصريح نقل البيانات خارج مصر** (السيرفر في ألمانيا والنسخ على درايف) + عقود
  DPA — أو نقل الاستضافة لمصر، وده اللي المحامي سمّاه «الخيار الأأمن». **وقرار
  داليا (٥ نوفمبر): الاستضافة الحالية مؤقتة والمفروض تنتقل لسيرفر في مصر.**
  🔴 **بشرط «الخوادم *والنسخ الاحتياطي* بالكامل داخل مصر»** — نقل السيرفر وحده مع
  بقاء النسخة على جوجل درايف مابيسقّطش الالتزام. وبرضه: حساب الدرايف لازم يكون
  **مؤسسيًا باسم الشركة** لا حسابًا شخصيًا.
- ✅ ~~قرار بلاي على الهوية المؤقتة في الغرف~~ — **مقفول**: الإقرار «١٨ وأكثر وبس» +
  Restrict Minor Access من ١٣ أكتوبر، ومن ٦ نوفمبر فيه حارس في السيرفر كمان
  (`identity: "temp"` بيترفض ٤٠٣ لغير البالغ). **فمفيش ادعاء ١٣–١٧ في أي خانة.**
- **الإشعارات على الموبايل مابتشتغلش في النسختين**: Web Push مابيشتغلش جوه
  WKWebView ولا جوه WebView أندرويد. محتاج FCM + APNs.

الترتيب العملي: ابني النسختين وجرّبيهما، وخلّي الرفع بعد ما البنود دي تتقفل.

## ٦) اللي ما اتجرّبش

- **أي بناء iOS** — مستحيل هنا (مفيش ماك ولا Xcode ولا CocoaPods). المتجرَّب:
  شكل المشروع وقيمه وملفاته، بالاختبارات في `server/test/iosBuild.test.ts`.
- **بناء الـAAB** — أول تشغيل حقيقي هيبقى على GitHub. و`targetSdk` اتنقل من ٣٥
  لـ٣٦ ومعاه AGP من 8.7.2 لـ8.9.2، وده تغيير في سلسلة البناء مابتتجرّبش عندنا
  (`dl.google.com` و`maven.google.com` محجوبان).
- **دورة رفع كاملة** على أي متجر.

**⚠️ وحاجة لقيتها برّه المطلوب ومالمستهاش:** شاشة البداية (splash) **بيضا** في
النسختين — دي صورة قالب Capacitor، والتطبيق غامق (`#14100F`)، فأول لحظة بعد
الضغط بتبقى ومضة بيضا. على أندرويد دي الحالة من أول APK فمش جديدة، إنما على
iOS هتبان كمان. تغييرها تصميم (صورة ٢٧٣٢×٢٧٣٢ بخلفية غامقة واللوجو في
النص) — قرارك.
