# APK للتجربة على جهاز حقيقي

## التنزيل

GitHub ← تاب **Actions** ← **«APK للموبايل»** ← آخر تشغيل ← قسم **Artifacts** ←
`raachat-apk`. بينزل zip جوّاه `app-debug.apk`.

ولو عايزة تشغّليه بإيدك (مثلًا بعنوان API مختلف): نفس الصفحة ← **Run workflow**
← تكتبي العنوان ← Run. وبيتشغّل تلقائي كمان مع أي push بيغيّر `src/` أو
`public/` أو `mobile/`.

**على الموبايل:** نزّلي الملف ← الإعدادات تطلب «السماح بتثبيت تطبيقات من هذا
المصدر» ← ثبّتي. (أندرويد بيحذّر من المصادر غير المعروفة — طبيعي لأي APK تجريبي.)

## ⚠️ خطوة لازمة مرة واحدة قبل أول تجربة

التطبيق جوه Capacitor أصله `https://localhost` (`androidScheme: "https"`) —
فلازم يبقى في `CORS_ORIGIN` وإلا **كل نداء من الـ APK بيترفض** والتطبيق يفتح
ويبان شغّال بس مفيش ولا رسالة بتتحمّل.

على السيرفر، شوفي القيمة الحالية:

```
grep ^CORS_ORIGIN= /opt/rachat/.env.production
```

وبعدين ضيفي `,https://localhost` **في آخر** القيمة (مش في أولها) وأعيدي تشغيل
الـ api. والترتيب كان مهم: `APP_URL` الفاضي بياخد أصلًا من القايمة، فلو المحلي
بقى أول واحد كان كل إيميل تحقق رابطه `https://localhost`. **الكود بقى بيعدّي
المحلي** (`firstPublicOrigin` في `senders.ts`، محمي باختبار سقط على السلوك
القديم) — فالترتيب بقى مش فارق، إنما الإضافة في الآخر تفضل الأنضف.

## إيه اللي يستاهل تتجرّب هنا بالتحديد

أغلب التطبيق ينفع يتجرّب من **المتصفح على الموبايل** (`https://app.kenoz.org`):
التنسيق، وتكبير سفاري، والمكالمات، والستوري والقنوات والاستطلاعات، وPush على
أندرويد. فالـ APK لازم **للحاجات اللي مستحيلة في المتصفح**:

| اللي يتجرّب | ليه الـ APK |
|---|---|
| **جهات الاتصال** | إضافة أصلية (`@capacitor-community/contacts`) — وهي سبب وجود «الأصدقاء» وما اتجرّبتش ولا مرة. المفروض تطلب صلاحية، وتطابق الأرقام **بلا تخزين** |
| **المايك في المكالمات والرسايل الصوتية** | صلاحية `RECORD_AUDIO` أصلية |
| **الكاميرا** | صلاحية `CAMERA` للصور والستوري |
| **الإشعارات على أندرويد** | `POST_NOTIFICATIONS` (من أندرويد ١٣ لازم طلب صريح) |
| **شكل التطبيق لما يبقى تطبيق** | شاشة البداية، وشريط الحالة، وزرار الرجوع الأصلي |

**وiOS مش مشمول:** الـ Web Push مابيشتغلش جوه Capacitor على iOS أصلًا — محتاج
FCM + APNs وجدول توكنات ومرسل في السيرفر، وده شغل لسه ما اتعملش.

## ليه على GitHub مش عند Claude

بناء أندرويد محتاج Android SDK من `dl.google.com` ومكتبات من
`maven.google.com` و`repo1.maven.org` — **التلاتة محجوبين** في allowlist الشبكة
بتاعة بيئة Claude (`403 CONNECT tunnel failed`، متفحوص ١٧ أكتوبر ٢٠٢٦). وJava
وGradle موجودين عند Claude، إنما من غير SDK ومكتبات مفيش بناء. وrunners بتاعة
جيت هب فيها الـ SDK مثبَّت.

**وفلاتر مش بديل:** نفس الحاجز بالظبط (نفس الـ SDK ونفس maven) **وزيادة** Flutter
SDK من `storage.googleapis.com` المحجوب — ومعاها إعادة كتابة التطبيق من React
لـ Dart، يعني رمي الواجهة كلها و١٠٦ اختبار، بلا أي تغيير في السيرفر.

## الحدود

- ده **debug APK** موقَّع بمفتاح التصحيح: للتجربة بس. الرفع للمتجر محتاج **مفتاح
  إصدار** (keystore) — سرّ يتحفظ في GitHub Secrets، وضياعه معناه إنك مش قادرة
  تحدّثي التطبيق على المتجر أبدًا. مش مطلوب للتجربة.
- `appId = com.datalifeai.raachat` (مشتق من دومين الشركة). **مابيتغيّرش بعد أول
  رفع للمتجر** — فلو عايزة اسمًا تانيًا، ده وقته.
- `targetSdkVersion = 35` حاليًا. **بلاي بيتطلّب ٣٦** للرفع — يتغيّر في
  `mobile/android/variables.gradle` وقتها، وسيبته ٣٥ دلوقتي عشان البناء التجريبي
  يبقى مضمون.
- **البناء نفسه ما اتشغّلش ولا مرة** — لا عندي (الشبكة) ولا على جيت هب لسه. فأول
  تشغيل هو أول تجربة حقيقية للوظيفة، ووارد يطلّع خطأ يتصلّح.
