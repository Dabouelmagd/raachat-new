# APK للتجربة على جهاز حقيقي

## التنزيل

**رابط عام ثابت (ده اللي الموقع التعريفي بيودّي عليه):**

```
https://github.com/Dabouelmagd/raachat-new/releases/latest/download/raachat.apk
```

الوظيفة بتنشر الـAPK كـ**Release** بوسم ثابت `apk-latest` بعد كل بناء ناجح على
`main`، وبتتأكد بنفسها إن الرابط بيردّ `200` وبحجم معقول قبل ما تخلص.

**🔴 ليه Release مش الـartifact:** تنزيل الـartifact **محتاج تسجيل دخول في
GitHub** — فزرار «نزّل» في الموقع كان هيودّي الزائر لصفحة دخول بدل الملف.
والوسم والاسم (`raachat.apk`) **عقد مع الموقع**: أي تغيير فيهم بيخلّي الزرار
٤٠٤ **في سكوت**، لأن الموقع صفحة ثابتة مابتفحصش الرابط. محمي بـ٣ اختبارات في
`androidBuild.test.ts`.

**⚠️ والرابط عام لأن الريبو عام.** لو الريبو بقى خاص، الزرار يموت ولازم بديل
(رفع الملف على السيرفر مثلًا).

ولو عايزة الـartifact بدل كده: GitHub ← تاب **Actions** ← **«APK للموبايل»** ←
آخر تشغيل ← قسم **Artifacts** ← `raachat-apk`.

ولو عايزة تشغّليه بإيدك (مثلًا بعنوان API مختلف): نفس الصفحة ← **Run workflow**
← تكتبي العنوان ← Run. وبيتشغّل تلقائي كمان مع أي push بيغيّر `src/` أو
`public/` أو `mobile/`.

**على الموبايل:** نزّلي الملف ← الإعدادات تطلب «السماح بتثبيت تطبيقات من هذا
المصدر» ← ثبّتي. (أندرويد بيحذّر من المصادر غير المعروفة — طبيعي لأي APK تجريبي.)

## ⚠️ خطوة لازمة مرة واحدة قبل أول تجربة

التطبيق جوه Capacitor أصله `https://localhost` (`androidScheme: "https"`) —
فلازم يبقى في `CORS_ORIGIN` وإلا **كل نداء من الـ APK بيترفض** والتطبيق يفتح
ويبان شغّال بس مفيش ولا رسالة بتتحمّل.

**و`CORS_ORIGIN` مش في `.env.production`** — مبنيّ جوه `docker-compose.prod.yml`
من `DOMAIN`. فالإضافة بتحصل بمفتاح `CORS_EXTRA` (اتضاف ١٨ أكتوبر ٢٠٢٦، لازم يبدأ
بفاصلة):

```
cd /opt/rachat
grep -q '^CORS_EXTRA=' .env.production || printf 'CORS_EXTRA=,https://localhost\n' >> .env.production
grep -n CORS_EXTRA .env.production
```

وبعدها نشرة عادية (`deploy-rachat.sh`) — بتعيد إنشاء الحاوية فالقيمة توصل
للعملية. والفحص الحاسم بعدها:

```
cd /opt/rachat
docker compose -f docker-compose.prod.yml --env-file .env.production exec -T api printenv CORS_ORIGIN
```

لازم يطلع فيه `https://localhost` **في الآخر**. والترتيب مهم: `APP_URL` الفاضي
بياخد أول أصل **غير محلّي** (`firstPublicOrigin` في `senders.ts`) — فلو الأصل
المحلي بقى الأول، كل إيميل تحقق لكل المستخدمين رابطه `https://localhost` واللوجو
مايظهرش، **والعطل صامت** لأن الإيميل بيوصل عادي. محمي باختبارين: واحد على قالب
الإيميل نفسه (`otp-email.test.ts`) وواحد على سطر compose (`composeEnv.test.ts`).

**⚠️ ودرس تشغيلي:** `docker compose up -d api` بيطلّع `Running` لما الإعداد ما
يتغيّرش — فـ`Running` بعد تعديل إعداد معناها إن التعديل **ما وصلش**، و`Started`
معناها إعادة إنشاء فعلية. والحكم النهائي هو `printenv` جوه الحاوية مش وجود
السطر في ملف.

## 🔴 لو كل نداء بيقول «غير مصرّح»

ده **عنوان API غلط**، مش عطل مصادقة ولا إيميل. حصل في أول APK (١٨ أكتوبر
٢٠٢٦): الوظيفة كانت بتبني بـ`https://api.kenoz.org/api` وبناء الواجهة في compose
بياخد `https://api.$DOMAIN` **بلا مسار**. ونجنكس وCaddy بيمرّروا المسار زي ما
هو، فExpress يستلم `/api/auth/otp/request`، مايطابقش أي راوت في `/auth`،
ويكمّل لراوتر فيه `r.use(requireAuth)` على كل المسارات → **401 «غير مصرّح» على
كل نداء**.

**مضلّل مرتين:** الرد مش 404 فمفيش حاجة تقول «المسار غلط»، والرسالة بتقول «غير
مصرّح» فالمطاردة تبدأ في المصادقة وResend. **القاعدة: العنوان أصل بلا أي مسار**،
ونفس اللي الواجهة بتستخدمه. والوظيفة بقت **تفشل** على أي عنوان فيه مسار (محمي
بـ`androidBuild.test.ts`، والحكم بتشغيل كتلة الحارس نفسها).

## إيه اللي يستاهل تتجرّب هنا بالتحديد

أغلب التطبيق ينفع يتجرّب من **المتصفح على الموبايل** (`https://app.raachateg.com`):
التنسيق، وتكبير سفاري، والمكالمات، والستوري والقنوات والاستطلاعات، وPush على
أندرويد. فالـ APK لازم **للحاجات اللي مستحيلة في المتصفح**:

| اللي يتجرّب | ليه الـ APK |
|---|---|
| **جهات الاتصال** | إضافة أصلية (`@capacitor-community/contacts`) — وهي سبب وجود «الأصدقاء». **اتجرّبت ١٩ أكتوبر وطلعت مكسورة واتصلحت** (`Capacitor.Plugins.X` بترجّع `undefined` في الـAPK — شوفي `src/mobile/capPlugin.ts`)، **ومحتاجة APK جديد عشان التصليح يوصل**. المفروض تطلب صلاحية، وتطابق الأرقام **بلا تخزين** |
| **المايك في المكالمات والرسايل الصوتية** | صلاحية `RECORD_AUDIO` أصلية |
| **الكاميرا** | صلاحية `CAMERA` للصور والستوري |
| **الإشعارات على أندرويد** | `POST_NOTIFICATIONS` (من أندرويد ١٣ لازم طلب صريح) |
| **شكل التطبيق لما يبقى تطبيق** | شاشة البداية، وشريط الحالة، وزرار الرجوع الأصلي |

**وiOS مش مشمول:** الـ Web Push مابيشتغلش جوه Capacitor على iOS أصلًا — محتاج
FCM + APNs وجدول توكنات ومرسل في السيرفر، وده شغل لسه ما اتعملش.

## ليه على GitHub مش عند Claude

بناء أندرويد محتاج Android SDK من `dl.google.com` ومكتبات من
`maven.google.com` و`repo1.maven.org` — **التلاتة محجوبين** في allowlist الشبكة
بتاعة بيئة Claude (`403 CONNECT tunnel failed`، متفحوص ١٧ أكتوبر ٢٠٢٦). وJava
وGradle موجودين عند Claude، إنما من غير SDK ومكتبات مفيش بناء. وrunners بتاعة
جيت هب فيها الـ SDK مثبَّت.

**وفلاتر مش بديل:** نفس الحاجز بالظبط (نفس الـ SDK ونفس maven) **وزيادة** Flutter
SDK من `storage.googleapis.com` المحجوب — ومعاها إعادة كتابة التطبيق من React
لـ Dart، يعني رمي الواجهة كلها و١٠٦ اختبار، بلا أي تغيير في السيرفر.

## الحدود

- ده **debug APK** موقَّع بمفتاح التصحيح: للتجربة بس. الرفع للمتجر محتاج **مفتاح
  إصدار** (keystore) — سرّ يتحفظ في GitHub Secrets، وضياعه معناه إنك مش قادرة
  تحدّثي التطبيق على المتجر أبدًا. مش مطلوب للتجربة.
- `appId = com.raachateg.app` (دومين التطبيق بالمقلوب: `raachateg.com`). اتغيّر
  ١٩ أكتوبر ٢٠٢٦ من `com.datalifeai.raachat` — **بلا تكلفة** لأن مفيش تطبيق منشور.
  **ومابيتغيّرش بعد أول رفع للمتجر.** و`cap sync` **مابيعيدش التسمية**، فالتغيير
  بالإيد في خمس حاجات (شوفي التعليق في `mobile/capacitor.config.ts`) ومحمي بحارس.
- **✅ و`VITE_API_URL` بقى `https://api.raachateg.com`** (١٩ أكتوبر ٢٠٢٦) — بعد ما
  الانتقال اتعمل والعنوان اتفحص فعلًا (`{"ok":true}`)، مش قبله. **والـAPK المثبَّت
  حاليًا على الجهاز لسه بيكلّم `api.kenoz.org` وشغّال** لأن الدومين القديم فاضل
  جنب الجديد بـ`OLD_DOMAIN` — فلو `OLD_DOMAIN` اتشال، لازم بناء APK جديد
  **قبلها**، وإلا التطبيق على الجهاز يفتح ويبان شغّالًا و**مفيش ولا رسالة تتحمّل
  ومفيش ولا خطأ** (نفس عطل ١٨ أكتوبر).
- `targetSdkVersion = 35` حاليًا. **بلاي بيتطلّب ٣٦** للرفع — يتغيّر في
  `mobile/android/variables.gradle` وقتها، وسيبته ٣٥ دلوقتي عشان البناء التجريبي
  يبقى مضمون.
- **البناء نفسه ما اتشغّلش ولا مرة** — لا عندي (الشبكة) ولا على جيت هب لسه. فأول
  تشغيل هو أول تجربة حقيقية للوظيفة، ووارد يطلّع خطأ يتصلّح.
