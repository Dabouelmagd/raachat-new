# قايمة الكلمات الممنوعة — مثال للشكل بس، **مفيهاش كلمات فعلية**.
#
# انسخي الملف ده بَرّه الريبو (مثلًا /root/banned.txt) واملأيه، وبعدين:
#   cd /opt/rachat && bash scripts/set-banned-words.sh /root/banned.txt
#
# ليه بَرّه الريبو: الكلام المسيء مايتحطّش في git، والقايمة بتتخزّن في
# .env.production بصلاحية 600.
#
# القواعد (السكربت بيفحصها ويرفض قبل أي ضبط):
#   • كل سطر كلمة واحدة، أو كلمات مفصولة بفاصلة.
#   • أقصر طول ٤ حروف. الفلتر بيطابق **جزءًا من النص**، فكلمة من حرفين أو
#     تلاتة بتبقى جوه كلام سليم كتير وتحجبه.
#   • التشكيل والتطويل وأشكال الألف والتاء المربوطة **مش مهمة** — الفلتر
#     بيطبّع الحروف، فـ«إهـــانة» و«اهانه» نفس الحاجة. اكتبي الشكل الأبسط.
#   • مفيش تكرار ومفيش كلمة جوه كلمة تانية في القايمة (الأقصر تكفي).
#   • السكربت بيجرّب القايمة على جُمل عربية سليمة، ولو حجبت أي واحدة **بيرفض**.
#
# الفلتر بيتطبّق على: نص الرسالة وتعديلها · أسماء الجروبات والغرف الصوتية
# والقنوات ووصفها · سؤال الاستطلاع وكل اختياراته.
#
# ⚠️ القايمة دي **سياسة محتوى**، مش إعداد تقني — اللي فيها بيحدّد كلام مين
# بيتمنع. راجعيها بنفسك (ومع المحامي لو فيها حدود حرة التعبير)، ومتوسّعيهاش
# أكتر من اللازم: الفلتر مابيفهمش سياقًا، وكل كلمة زيادة = احتمال حجب كلام بريء.

# ════ قاعدتان اتعلمناهم وإحنا بنجهّز أول مسوّدة (١٤ أكتوبر ٢٠٢٦) ════
#
# ١) **القايمة الصغيرة الدقيقة أفضل من الكبيرة.** جرّبنا ٣٣ كلمة، فطلع إن ١٣
#    منهم بيحجبوا كلام سليم تمامًا — الفلتر بيطابق **جزءًا من النص** ومابيفهمش
#    سياقًا. أمثلة حقيقية اتكشفت:
#      «جنسيه» ← بتحجب «الجنسية المصرية»
#      «كلبه»  ← بتحجب «كلبه لطيف» (كلب + هاء الملكية)
#      «متخلف» ← بتحجب «متخلف عن السداد»
#      «نصاب»  ← بتحجب «النصاب القانوني»
#      «احتيال» و«عنصري» ← الكلمتين بيُستخدمان **للتحذير والشكوى** مش للإساءة
#    فخلّي القايمة على الكلمات اللي **عمرها ما تيجي في كلام سليم**، وسيبي
#    الباقي للبلاغ والمراجعة البشرية — وهما موجودان في التطبيق.
#
# ٢) **كلمات الأزمة ممنوعة تمامًا** (انتحار · إيذاء النفس وما شابه). اللي بيقول
#    «بفكر في الانتحار» محتاج يوصل لحد، والحجب بيسكّته في سكوت. دي حالة
#    بلاغ ومساعدة مش حالة فلتر. والفحص بيرفض أي قايمة فيها الكلمات دي.
#
# ومش لازم تغطّي كل حاجة: الفلتر خط أول خشن، والبلاغ + قسم «البلاغات» في
# لوحة الإدارة هما اللي بيشيلوا الحالات اللي محتاجة فهم سياق.
